# Day 1: DevOps

DevOps is a way of working where development and operations share responsibility for delivering and running software reliably.

## Three main ideas

- Collaboration: developers and operations work together to solve problems.
- Automation: repeatable work such as testing and deployment is performed consistently by tools.
- Feedback: tests, logs, monitoring, deployment results and user reports show whether a change works.

## Learning flow

Change code -> Run tests -> Deploy -> Monitor -> Learn -> Improve

## Practice

Draw this flow for the learning API and answer:

- What would another person need to run the application?
- Which repeated step could be automated?
- How would I know a deployment is broken?

## Summary

DevOps brings people together, automates repeated work, and uses feedback to deliver and run software reliably.
